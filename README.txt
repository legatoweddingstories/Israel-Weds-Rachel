ISRAEL & RACHEL — WEDDING INVITATION WEBSITE

FILES
- index.html: the complete wedding invitation website.
- README.txt: these instructions.

UPLOAD / REPLACE ON GITHUB
1. Open your joe-sneha-wedding repository.
2. Choose Add file > Upload files.
3. Extract this ZIP on your computer first.
4. Upload index.html and README.txt from the extracted folder.
5. If GitHub says index.html already exists, choose to replace/overwrite it.
6. Commit changes to the main branch.

The website keeps “Israel & Rachel” on the cover, browser title and footer.
The formal invitation section retains the full names:
Joe Israel Stanly and Sneha Rachel Mathew, with their family details.

The Google Maps button opens directions to Cochin Club.
The RSVP button still needs your Google Form URL.
Background music requires you to add your own MP3 named wedding-music.mp3
to the same repository folder as index.html.
